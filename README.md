## Development

### Setup

Clone the repository:
```bash
git clone https://github.com/josephchay/yawnoc-pixel-game/
```

Navigate to the project directory:
```bash
cd yawnoc-pixel-game
```

Create a virtual environment:
```bash
pip install -r requirements.txt
```

Run the game with:
```bash
python main.py
```
